Howpsuzlyk problemalary

Köp duş gelýän howpsuzlyk meseleleri

  • Firewall bloklaýar – programma ýa-da portyň bloklanmagy. Firewall sazlamalaryny barlaň.
  • Wi-Fi paroly gowşak – WPA2 ýa-da WPA3 ulanyň, çylşyrymly parol belläň.
  • Router-yň dolandyryş paneli açyk – Router-a girmek üçin parol belläň, default paroly üýtgediň.
  • ARP poisoning / spoofing – Tor ulgamynda hüjüm bolup biler. Static ARP ýa-da switch-de port howpsuzlygy ulanyň.
  • DDoS hüjümi – Tor ulgamynda aşa trafik bolsa, router-y reboot ediň, ýa-da ISP-e habar beriň.

Firewall barlagy

Windows-da: "Windows Defender Firewall" → "Allow an app through firewall"

Linux-da: sudo ufw status (UFW ulanylsa)
