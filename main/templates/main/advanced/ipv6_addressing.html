IPv6 adresleme

Global Unicast: 2000::/3 – internetde ulanylýan umumy adresler.

Link-Local: fe80::/10 – bir tor segmentinde (link) ulanylýar, router bilen gürleşmek üçin. Awto-konfigurasiýa.

Unique Local: fc00::/7 – hususy tor (NAT ýaly, ýöne global ýagtyda ýöremeýär).

Multicast: ff00::/8 – bir topar enjama maglumat ibermek.

Adres bölünişi: 64 bit tor, 64 bit host (Interface ID). Interface ID köplenç MAC adresden (EUI-64) emele gelýär.

Stateless Autoconfiguration (SLAAC): Enjam routerdan alan maglumat esasynda öz-özüne adres belleýär.
