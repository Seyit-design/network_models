Fiziki we Maglumat baglanyşyk gatlagy (TCP/IP Layer 5)

OSI bilen deňeşdirme: Bu gatlak OSI modeliniň Fiziki (Layer 1) we Maglumat baglanyşyk (Layer 2) gatlaklaryny birleşdirýär.

Bu gatlak näme üçin döredildi?

TCP/IP modeli işlenip düzülende, fiziki gurşaw we maglumat baglanyşyk gatlaklaryny birleşdirmek kararyna gelindi. Sebäbi bu iki gatlak özara berk baglanyşykly we köplenç bir protokollar toplumy hökmünde işleýär (meselem, Ethernet).

Esasy wezipeleri:

  • Bitleriň fiziki gurşawda äkidilmegi (kabel, radio, optiki süýüm)
  • MAC adresleriň kömegi bilen enjamlary tanamak
  • Frame-lary döretmek we ibermek
  • Ýalňyşlyklary anyklamak we düzetmek (FCS, CRC)
  • Media girişini dolandyrmak (CSMA/CD, CSMA/CA)

Bu gatlakda ulanylýan tehnologiýalar we protokollar

📡 Fiziki tehnologiýalar:
  • Ethernet: 10BASE-T, 100BASE-TX, 1000BASE-T (Cat5, Cat6 kabeller)
  • Fiber optika: Single-mode, Multi-mode
  • Wi-Fi: IEEE 802.11 a/b/g/n/ac/ax
  • Bluetooth: 802.15.1
  • Koaksial kabel: Köne torlarda we telewideniýede
🖧 Maglumat baglanyşyk protokollary:
  • Ethernet (IEEE 802.3): Iň giň ýaýran protokol
  • Wi-Fi (IEEE 802.11): Simsiz torlar üçin
  • PPP (Point-to-Point Protocol): Nokatdan-nokada baglanyşyk
  • HDLC: Synhron baglanyşyklar üçin
  • ARP (Address Resolution Protocol): IP adresden MAC adres tapmak

Frame (çarçuwa) gurluşy

Ethernet frame-iň düzümi:

Preamble (7 baýt) SFD (1 baýt) Destination MAC (6 baýt) Source MAC (6 baýt) Type/Length (2 baýt) Data (46-1500 baýt) FCS (4 baýt)

FCS (Frame Check Sequence): CRC algoritmi bilen ýalňyşlyklary anyklaýar.

MAC adres we onuň gurluşy

MAC adres 48 bitlik (6 baýt) bolup, 16-lyk san ulgamynda ýazylýar.

Mysal: 00:1A:2B:3C:4D:5E
Ilkinji 3 baýt (00:1A:2B): Öndürijiniň identifikatory (OUI)
Soňky 3 baýt (3C:4D:5E): Enjamyň unikal belgisi

MAC adres enjamyň tor kartyna önümçilik wagty ýazylýar we üýtgemeli däl (köplenç).

Praktiki mysal: Ethernet switch-iň işleýşi

Switch özüne birikdirilen enjamlaryň MAC adreslerini ýatda saklaýar (MAC tablisa).

MAC tablisa:
MAC adresPort
AA:AA:AA:AA:AA:AA1

PC1 (port 1) PC3 (port 3) -e maglumat ibermekçi bolsa:

  1. PC1 frame döredýär (destination MAC = CC:CC:CC:CC:CC:CC)
  2. Switch frame alýar we MAC tablisadan CC:CC:CC:CC:CC:CC -iň port 3-dedigini görýär
  3. Frame diňe port 3-e iberilýär (beýleki portlara iberilmeýär)

Bu gatlakda işleýän enjamlar

  • Switch (kommutator): Frame-lary MAC adres esasynda ugrukdyrýar
  • Bridge (köpri): Iki tor segmentini birleşdirýär
  • NIC (Tor karty): Enjamy tora birleşdirýän fiziki enjam
  • Hub (multipleksor): Fiziki gatlakda işleýär (köne tehnologiýa)
  • Access point: Simsiz enjamlary tora birleşdirýär

Ýalňyşlyklary anyklamak (CRC)

Ethernet frame-inde FCS (Frame Check Sequence) ýalňyşlyklary anyklamak üçin ulanylýar. CRC (Cyclic Redundancy Check) algoritmi bilen hasaplanýar.

Iberiji: "Salam" -> CRC = 0x1A2B
Alyjy: "Salam" -> CRC = 0x1A2B (deň -> ýalňyş ýok)
Eger "Salam" -> CRC = 0x3F4C bolsa, ýalňyş bar!
