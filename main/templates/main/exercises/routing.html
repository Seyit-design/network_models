Routing maşklary

1. Gönükme (Static route)

Router-da 192.168.2.0/24 toryna 10.0.0.2 next-hop bilen static route ýazyň.

ip route 192.168.2.0 255.255.255.0 10.0.0.2

2. Gönükme (Default route)

Ähli näbelli trafigi 10.0.0.1-e iberýän default route ýazyň.

ip route 0.0.0.0 0.0.0.0 10.0.0.1

3. Gönükme (OSPF)

OSPF process ID 1 bilen işlediň we 192.168.1.0/24 toryny area 0-a goşuň.

router ospf 1
 network 192.168.1.0 0.0.0.255 area 0

4. Gönükme (Routing tablisasyny analiz etmek)

Berlen routing tablisasynda:

C    192.168.1.0/24 is directly connected, FastEthernet0/0
S    10.0.0.0/8 [1/0] via 172.16.1.1
O    172.16.0.0/16 [110/2] via 192.168.1.2, 00:00:12, FastEthernet0/0
