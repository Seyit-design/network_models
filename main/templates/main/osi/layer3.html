Ulgam gatlagy (Layer 3)

Gelip çykyşy we wezipeleri

Ulgam gatlagy 1970-nji ýyllaryň ortalarynda dürli torlaryň özara birleşmegi üçin döredildi. IP protokolynyň (Internet Protocol) döredilmegi bilen bu gatlagyň ähmiýeti has-da artdy.

Esasy wezipeleri:

  • Mantiýsy adresleme (IP adresler)
  • Marşrutizasiýa (iň gowy ýoly saýlamak)
  • Paketleri böleklere bölmek we birleşdirmek (fragmentation)
  • Tor gürpüldisini dolandyrmak
  • Marşrut tablisalaryny dolandyrmak

Marşrutizasiýa animasiýasy

R1 -> R2 -> R4 ýa-da R1 -> R3 -> R4 ýoly bilen gitmeli. Marşrut protokoly iň gysga ýoly saýlar.

Protokollar

Marşrut protokollary
  • RIP (Routing Information Protocol)
  • OSPF (Open Shortest Path First)
  • EIGRP (Enhanced Interior Gateway)
  • BGP (Border Gateway Protocol)
Ulgam protokollary
  • IP (Internet Protocol)
  • ICMP (Internet Control Message)
  • ARP (Address Resolution)
  • DHCP (Dynamic Host Configuration)
Enjamlar
  • Router (marşrutizator)
  • Layer 3 switch
  • Firewall

Praktiki mysal: traceroute

Traceroute komandasy bilen paketiň geçýän routerlaryny görmek bolýar:

$ traceroute google.com
1 192.168.1.1 (2 ms)
2 10.0.0.1 (5 ms)
3 172.16.1.1 (10 ms)
4 8.8.8.8 (15 ms)

Her bir hop (böküş) paketiň bir routerdan geçendigini görkezýär.
