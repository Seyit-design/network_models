Maglumat baglanyşyk gatlagy (Layer 2)

Gelip çykyşy we wezipeleri

Maglumat baglanyşyk gatlagy 1970-nji ýyllarda Ethernet tehnologiýasy bilen birlikde işlenip düzüldi. Bu gatlak fiziki gatlagyň üstünde ygtybarly maglumat geçişini üpjün etmek üçin döredildi.

Esasy wezipeleri:

  • Fiziki adresleme (MAC adresler)
  • Frame (çarçuwa) döretmek
  • Ýalňyşlyklary anyklamak we düzetmek
  • Akymy dolandyrmak
  • Media girişini dolandyrmak (CSMA/CD, CSMA/CA)

MAC adresler

MAC adres (Media Access Control) - her tor enjamyna önümçilik wagty berilýän ýeke-täk 48 bitlik adres. Ol 6 baýtdan ybarat we 16-lyk san ulgamynda ýazylýar.

Mysal: 00:1A:2B:3C:4D:5E
Ilkinji 3 baýt (00:1A:2B) - öndürijini kody, soňky 3 baýt (3C:4D:5E) - enjamyň unikal belgisi

Frame gurluşy

Ethernet frame gurluşy:

Preamble (7 baýt) SFD (1 baýt) Destination MAC (6 baýt) Source MAC (6 baýt) Type/Length (2 baýt) Data (46-1500 baýt) FCS (4 baýt)
Frame 1

Protokollar we enjamlar

Protokollar:
  • Ethernet (IEEE 802.3)
  • Wi-Fi (IEEE 802.11)
  • PPP (Point-to-Point Protocol)
  • HDLC (High-Level Data Link Control)
  • Frame Relay
  • ATM (Asynchronous Transfer Mode)
Enjamlar:
  • Switch (kommutator) - MAC adres esasynda frame-lary ugrukdyrýar
  • Bridge (köpri) - iki tor segmentini birleşdirýär
  • NIC (Tor karty) - enjamy tora birleşdirýär

Praktiki mysal: Switch-iň işleýşi

Switch özüne birikdirilen enjamlaryň MAC adreslerini ýatda saklaýar (MAC tablisasy). PC1 (MAC: AA:AA:AA:AA:AA:AA) PC2 (MAC: BB:BB:BB:BB:BB:BB) -e maglumat ibermek islände:

  1. PC1 frame döredýär: Destination MAC = BB:BB:BB:BB:BB:BB, Source MAC = AA:AA:AA:AA:AA:AA
  2. Switch frame alýar we MAC tablisasyny barlaýar
  3. Eger BB:BB:BB:BB:BB:BB port 2-de bolsa, frame diňe şol porta iberilýär
MAC tablisa:
MAC adresPort
AA:AA:AA:AA:AA:AA1
BB:BB:BB:BB:BB:BB2

ARP protokoly

ARP (Address Resolution Protocol) - IP adresden MAC adres tapmak üçin ulanylýar.

ARP işleýşi:

PC1 (192.168.1.10) → ARP sorag: "Kimde 192.168.1.20 bar?" → PC2 (192.168.1.20)
PC2 → ARP jogap: "Men! MAC: BB:BB:BB:BB:BB:BB"
